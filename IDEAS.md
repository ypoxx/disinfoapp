## UI/UX Ideas

### SwipeFeed Enhancements
- [ ] **Haptic feedback** on swipe (mobile devices)
- [ ] **Sound effects** (optional, muted by default)
- [ ] **Confetti animation** when completing all cards
- [ ] **Bookmark/favorite** system for saving techniques
- [ ] **Search within feed** - jump to specific technique
- [ ] **Category filters** - show only certain categories
- [ ] **Difficulty filters** - beginner/advanced mode

### Gamification
- [ ] **Streak rewards** - special badges for 7-day, 30-day streaks
- [ ] **Daily quiz** - one quick question per day
- [ ] **Spaced repetition** - resurface techniques user got wrong
- [ ] **Progress sharing** - share achievements on social media
- [ ] **Competitive mode** - compare with friends/colleagues

### Accessibility
- [ ] **Voice-over support** - read cards aloud
- [ ] **High contrast mode** - for visual impairments
- [ ] **Font size adjustment** - user preference
- [ ] **Reduce motion** - option to disable animations
